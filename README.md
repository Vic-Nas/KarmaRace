A reciprocity-based testing network for indie founders and startup builders.

## How It Works

Founders publish quick tasks — star our GitHub repo, fork it, comment on Product Hunt, or verify via webhook. Other founders complete tasks to earn karma. Your karma score determines your visibility in the feed. High-karma contributors get prioritized.

## Task Types

- GitHub Star / Fork
- Product Hunt Comment & Upvote
- Webhook verification (Pro)

## Why It Works

Real testing actions, not vanity metrics. Server-side verification. Fair visibility driven by contribution, not budget.

Free tier available. Pro unlocks webhook task publishing and advanced notifications.
