What KarmaRace is, how it works, and API expectations.

What Is KarmaRace?

KarmaRace is a task exchange app where users publish verifiable tasks and other users complete them to earn karma. Feed visibility is influenced by owner karma, while task checks determine reward transfers.

How It Works

  1. Create a task in My Tasks.
  2. Publish the task (must pass configuration and health checks).
  3. A tester opens the feed and presses Check.
  4. If verification succeeds, tester gains karma and owner pays the task reward.
  5. Completion also settles or creates reciprocity obligations by task type.

Reciprocity Lock

Reciprocity is always on. If you have open obligations, your feed is automatically restricted to tasks that can satisfy them. During this state, archive/skip is disabled until obligations are cleared.

Task Types

  • GitHub Star: target format owner/repo.
  • GitHub Fork: target format owner/repo.
  • Product Hunt Comment/Upvote: target format slug.
  • Webhook: target format full URL (Pro only).

API Calls and Expected Return

When a webhook task is checked (and during publish health checks), KarmaRace sends:

POST {task.target_id}
Content-Type: application/json
Authorization: Bearer {task.webhook_secret}  # only if secret is set

{
  "task_slug": "webhook-vic-https-example-com-verify",
  "platform_username": "tester_username"
}

Expected response:

{
  "verified": true
}

or

{
  "verified": false
}

If verification fails, KarmaRace reports Sent/Expected/Got diagnostics to help debugging.

Linked Accounts

Connect GitHub and Product Hunt from Linked Accounts. OAuth tokens are used for verification requests. If checks fail due to missing token, disconnect and reconnect the provider.

Common Publish Failures

  • Webhook tasks are Pro-only.
  • GitHub repo is private or missing.
  • Product Hunt slug is invalid or post not found.
  • Webhook endpoint is unreachable or does not return JSON with a boolean verified field.
