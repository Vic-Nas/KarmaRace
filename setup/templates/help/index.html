Help Center

Everything you need to get started and earn karma.

What Is KarmaRace?

KarmaRace is a task exchange community. You post tasks for other developers to complete — like starring or forking your GitHub repository — and in return you complete tasks for others. Everyone earns karma, and karma determines how visible your tasks are in the feed.

Getting Started

  1. Link your accounts. Go to Accounts and connect GitHub (required for GitHub tasks) and Discord (optional, gives you access to our community server).
  2. Create a task. Go to My Tasks and create your first task — choose a GitHub repo to star or fork.
  3. Publish it. Hit Publish on your task to make it visible in the feed. New tasks start hidden until published.
  4. Complete tasks for others. Browse the feed, pick a task, and hit Check. Verification is automatic — your karma goes up on confirmation.

The Feed

The feed shows tasks from other users ranked by task reward(function of owner karma), then creation time. You never see your own tasks in the feed.

Use the filters to narrow down by completion status, archive status, or task type (GitHub Star, GitHub Fork, Webhook).

Karma and Reciprocity

When you complete a task, you earn karma and the task owner pays karma. Reciprocity is always on — if someone completes a task for you, a reverse obligation is created. When you have an open obligation and a matching task is available, your feed is restricted to that task until it's settled. If no matching task is available, the feed falls back to normal.

Task Types and Verification

  • GitHub Star — target format owner/repo. Verified against the tester's linked GitHub account.
  • GitHub Fork — target format owner/repo. Verified against the tester's linked GitHub account.
  • Webhook — target is a full URL. Pro-only. Verified by your endpoint's JSON response (see below).

For GitHub tasks, the repo is selected from a dropdown of discovered repositories. Use Reload repos if a recently created repo isn't showing up.

Webhook Contract

When a webhook task is checked, KarmaRace sends a POST request to your endpoint:

POST {your_webhook_url}
Content-Type: application/json
Authorization: Bearer {task.webhook_secret}

{
  "task_slug": "your-task-slug",
  "google_email": "tester@gmail.com",
  "signature": "<hmac-sha256>"
}

google_email is the Google-verified address the tester selected — the email they registered with on your platform. The tester picks from their verified emails in Accounts before submitting the check.

Verify the signature to confirm the payload was sent by KarmaRace and not spoofed:

import hmac, hashlib

expected = hmac.new(
    webhook_secret.encode(),
    f"{task_slug}:{google_email}".encode(),
    hashlib.sha256,
).hexdigest()

assert hmac.compare_digest(expected, signature)

Your endpoint must respond with:

{ "verified": true }

If verification fails, the tester sees a generic error. You receive detailed diagnostics in Notifications.

Notification Events

Notification events are always available in-app. Pro users can additionally enable webhook and Discord delivery per event.

  • TASK_CONFIRMED — {"task_id": number, "delta": number}
  • TASK_HEALTH_FAILED — {"task_id": number, "task_type": string, "target_id": string}
  • WEBHOOK_CHECK — {"task_id": number, "phase": string, "status": string, ...}
  • KARMA_LOW / KARMA_RESTORED — {"delta": number, "balance": number, "threshold": number}
  • APPRECIATION — {"message": string}

Task Health

Every webhook call outcome is counted toward a positive/negative health ratio. When the negative ratio exceeds the configured threshold (after a minimum sample size), the task is auto-unpublished and you're notified.

Linked Accounts

Go to Accounts to connect GitHub and Discord. OAuth tokens are used for verification. If checks start failing due to a token issue, disconnect and reconnect the provider. On Discord link, KarmaRace joins your account to the configured guild, assigns your role, and syncs your nickname to your app username.

Why Did My Publish Fail?

  • Webhook tasks require a Pro account.
  • GitHub repository is private or has been deleted.
  • Webhook URL is not a valid http:// or https:// address.
